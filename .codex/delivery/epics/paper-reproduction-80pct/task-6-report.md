## What changed and why

### Shared scientific contracts and actual consumers

`rsl_rl/navigation_reward.py` implements the seven raw terms with explicit upstream versus paper-diagnostic formulas. The independent scalar oracle table drives tests; expectations are not generated by the implementation. Gym consumes raw terms using its inherited once-prepared dt-scaled coefficients; all three adapter entries call the shared terms and apply dt once. Reward owns current physical goal geometry, not held sensor goal data. Gym applies raw weights, contact-compatible terms, stay threshold, commands and horizon before its task constructor/reward preparation. Unsupported active extra reward terms and nonintegral policy-tick horizons are rejected.

`rsl_rl/perception_delay.py` provides preallocated, masked timestamped acquisition/hold state. Upstream acquires each policy tick and refreshes every 100 ms using the source two/three-tick-old choices; separate paper-diagnostic math models 10 Hz acquisition with uniform transport latency. Reset is synthetic, noise-free step 0; neighboring rows are unchanged. Integer epoch-relative scheduling closes the independently reproduced float32 missed-tick defect. Sample timestamps remain actual input timestamps, not invented ideal wall time. Actual Gym and all three adapter observation/reset callers use the helper. Trace now distinguishes sampled latency from actual held sample age at the observation/decision timestamp.

`rsl_rl/environment_profile.py` deep-materializes nested class configuration per run without discarding ordinary runtime-contract methods; keeps immutable resolved dataclasses intact; applies the Task 4 real constructor converters and Task 5 replay/ACSI bridge. Replay reconstruction delta is required even when replay is disabled. Adapters reconcile actual constructor options (including learning rate, entropy, std and geometry) and environment settings with preflight. Ordinary PPO now consumes ten-tick position history, shared ACSI collision-onset probability and normal-reset curriculum; it remains explicitly one-environment/no-replay. Smoke stops at the first selected done and is not an evaluator.

All three adapter mains no longer purge the bundled `rsl_rl` after preflight. A foreign preloaded package is rejected; actual preloaded core/config type identity is retained. Raw checkpoint loads and post-construction `cbf_layer` replacement were removed from guarded startup; there is one profile-aware construction path.
